# Parcel Intelligence — website

Landing page and privacy policy for the **Parcel Intelligence** Chrome extension,
served with GitHub Pages.

- Site: https://elmagoct.github.io/parcel-intelligence/
- Privacy policy: https://elmagoct.github.io/parcel-intelligence/privacy.html

The extension shows your own orders and parcels on a map, with delivery estimates
learned from your own delivery history. All of its data stays in your browser: no account,
no backend, no telemetry.

This repository contains only the public website.
The extension source lives at
<https://github.com/ElMagoCT/aliexpress-parcel-intelligence>.
